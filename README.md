Leonida Polaroid Press — a postcard-style GTA 6 cover maker. Tilted polaroid snapshots with tape and handwritten captions, diagonal cuts, a contact-sheet layout, a halftone title block and outlined gradient lettering. Six layouts, six colour grades, four procedural Vice City scenes drawn entirely in code (Ocean Drive sunset, a neon street, a beach at dusk, a downtown skyline at night), drag-to-reframe with scroll zoom, undo/redo, shuffle, and PNG export at 1080×1080, 1080×1350 and 1920×1080. Fully offline — no photos, fonts or requests leave the browser.

## Run it

```sh
MAKEFUN_OUTPUT_DIR=out node main.ts
```
